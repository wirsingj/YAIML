# Instructions For Agents

Before meaningful work, read `yaiml.yml` and then the core YAIML documents it declares.

Read each selected document's stable header before its body. Load supporting material only when task-relevant. See the Maintainer Guide for YAIML refresh and compression.

Before finishing meaningful work, update only affected YAIML documents without waiting for a separate request. Respect read-only scope and leave unchanged memory alone. Preserve verified facts, declared direction, uncertainty, and disagreements. Replace changed facts, remove resolved active items, and keep lessons only when they change future action. Do not append a work log or move it into supporting files. Measure affected memory before/after; report justified growth and budget overages in the task response.
