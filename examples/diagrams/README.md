# Editable Diagram Example

[Minimal Notes architecture](minimal-notes.drawio) is a draw.io view of the existing fictional [SoT](../minimal-notes/SOT.md) and [Architecture](../minimal-notes/ARCHITECTURE.md). Open it in draw.io to edit its shapes, connections and source metadata.

The components are declared design, not implemented software. Dashed arrows are explicitly inferred collaboration; the source documents do not define those interfaces. The diagram keeps that distinction visible instead of presenting a polished picture as implementation evidence.

Its source snapshot is Git `7b4bee84fb4bb1dd769b0cc4144717ea3919afc4`; those two source files were unchanged when this view was created on 2026-10-31. Source paths in the diagram are relative to this repository root. The original documents remain authoritative; this view is not automatically synchronized.

The [diagram skill](../../reference/skills/yaiml-diagram/SKILL.md) is reusable. This completed example is not part of the acquired skill package and must not become an adopter's project facts. It adds no application code to the minimal example.
