# YAIML Examples

These fictional projects show how project-specific memory differs from reusable YAIML guidance. They are examples to read, not files to copy into an unrelated project.

| Example | What to explore |
| --- | --- |
| [Minimal Notes](minimal-notes/README.md) | A small memory family, agent instructions and a paste-and-go demonstration. |
| [Canopy Dispatch](canopy-dispatch/docs/SoTD.md) | A larger project's current state, architecture, maintainer procedures and release/trust concerns. Its [discovery map](canopy-dispatch/yaiml.yml) locates the family. |

Both intentionally preserve legacy layouts from before revision tracking. They are useful upgrade inputs, not snapshots of the current init output. For a new setup, use [full init](../reference/prompts/init-yaiml.md) or [offline init](../reference/prompts/init-yaiml-offline.md).

For measured exercises rather than fictional examples, see [evaluation and case studies](../docs/evaluation/EVALUATION.md). Return to the [documentation guide](../docs/README.md) for the convention itself.
