# yaiml-orient

Follow [Using YAIML — Start And Select](../../YAIML_GUIDE.md#start-and-select). Use this method for explicit orientation, handoff recovery or missing context; ordinary work can use the guide directly.

Recover current direction, constraints, state and consequential unknowns from the actual project. Reconcile stale remembered context with the checkout. For an explicit orientation request, report a concise working understanding: current objective, relevant state and constraints, consequential unknowns and next action, with source pointers where they help. For embedded orientation, surface only information needed for the active task. Then continue the requested task; orientation alone does not start backlog work. Missing discovery calls for locating established owners, not regenerating them or acquiring upstream guidance.
