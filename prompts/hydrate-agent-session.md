# Hydrate A New Agent Session

You are starting work in a repository that may use YAIML.

## Task

1. Find and read `yaiml.yml` if it exists.
2. Use it to locate YAIML documents.
3. For each document, read the stable header before the body.
4. Read SoT first unless the human request clearly requires a narrower entry point.
5. Read Architecture and Maintainer Guide before making substantial changes.
6. Inspect relevant repository reality to verify claims needed for the current task.
7. Build a concise project model:
   - current state;
   - declared direction;
   - architecture boundaries;
   - maintainer procedures;
   - active risks;
   - known divergence;
   - open uncertainty.
8. Identify stale claims, contradictions, dead commands, or missing evidence.
9. Proceed with the requested work only after the project model is coherent enough.

## Authority Rules

- Humans define project intent.
- Code, tests, and runtime behavior establish implementation reality.
- YAIML documents own only the memory declared in their stable headers.
- Conflicts must be surfaced, not blended into confident prose.

## Output

Before acting, briefly report:

- which YAIML documents were read;
- the working project model;
- contradictions or freshness concerns;
- what you still need to verify for the requested task.
